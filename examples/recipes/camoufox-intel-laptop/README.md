# Camoufox as a Windows laptop with Intel graphics

Pick the GPU the persona reports with `webgl_config` (vendor and renderer from Camoufox's database) and keep the rest generated: a common office laptop instead of a random desktop.

- [Node.js](node/example.mjs)
- [Python](python/example.py)
- [Java](java/Example.java)
- [C#](csharp/Program.cs)
- [Go](go/main.go)

Set `CDPFLEET_API_KEY` and replace the placeholder proxy with yours. Install the client named at the top of each file.
