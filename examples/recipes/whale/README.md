# Naver Whale

Naver's browser (Whale 5.39 on Chromium 150): `Whale/…` in the user agent and `Whale` in the client hints — what Korean sites see from Naver's own browser. Headless here (1 thread); the user agent then says `HeadlessChrome`, so run headful for sites that check.

- [Node.js](node/example.mjs)
- [Python](python/example.py)
- [Java](java/Example.java)
- [C#](csharp/Program.cs)
- [Go](go/main.go)

Set `CDPFLEET_API_KEY` and replace the placeholder proxy with yours. Install the client named at the top of each file.
