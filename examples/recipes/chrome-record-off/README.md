# Headful Chrome that isn't recorded

Headful sessions are [recorded](https://cdpfleet.com/docs/recordings) by default within your plan's limits; `"record": false` opts one launch out — for pages with personal or sensitive data, or runs you never need to replay. Nothing is uploaded for that session.

- [Node.js](node/example.mjs)
- [Python](python/example.py)
- [Java](java/Example.java)
- [C#](csharp/Program.cs)
- [Go](go/main.go)

Set `CDPFLEET_API_KEY` and replace the placeholder proxy with yours. Install the client named at the top of each file.
