# Yandex Browser

Yandex's own browser (26.8 on Chromium 150): `YaBrowser/26.8` in the user agent, and `YaBrowser` and `Yowser` in the client hints. Headless here (1 thread), so the user agent says `HeadlessChrome`; run headful for sites that check.

- [Node.js](node/example.mjs)
- [Python](python/example.py)
- [Java](java/Example.java)
- [C#](csharp/Program.cs)
- [Go](go/main.go)

Set `CDPFLEET_API_KEY` and replace the placeholder proxy with yours. Install the client named at the top of each file.
