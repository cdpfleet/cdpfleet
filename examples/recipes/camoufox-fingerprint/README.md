# Camoufox with a Windows fingerprint

A consistent identity at launch: Windows, US English, human-like mouse movement, WebRTC disabled. Camoufox also matches its location to your proxy.

- [Node.js](node/example.mjs)
- [Python](python/example.py)
- [Java](java/Example.java)
- [C#](csharp/Program.cs)
- [Go](go/main.go)

Set `CDPFLEET_API_KEY` and replace the placeholder proxy with yours. Install the client named at the top of each file.
