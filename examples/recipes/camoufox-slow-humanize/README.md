# Camoufox with slower, human-paced cursor moves

Camoufox moves the cursor along natural paths by default; `humanize: 2` lets each move take up to 2 seconds — slower clicks for sites that score how fast a visitor's pointer travels. `humanize: false` turns it off.

- [Node.js](node/example.mjs)
- [Python](python/example.py)
- [Java](java/Example.java)

Set `CDPFLEET_API_KEY` and replace the placeholder proxy with yours. Install the client named at the top of each file.
