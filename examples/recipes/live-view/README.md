# Live view: stream the page to your code

Watch the remote browser while your code drives it: `page.screencast` sends a JPEG frame whenever the page changes (Playwright 1.60+). See [Live view](https://cdpfleet.com/docs/live-view).

- [Node.js](node/example.mjs)
- [Python](python/example.py)
- [Java](java/Example.java)
- [C#](csharp/Program.cs)
- [Go](go/main.go)

Set `CDPFLEET_API_KEY` and replace the placeholder proxy with yours. Install the client named at the top of each file.
