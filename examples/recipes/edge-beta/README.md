# Microsoft Edge, beta channel

A real Edge with the `Edg/` user-agent token and the `Microsoft Edge` client-hint brand. `"beta"` and `"dev"` run the next releases; omit `channel` for stable. See [Chrome vs Edge](https://cdpfleet.com/docs/compare/chrome-vs-edge).

- [Node.js](node/example.mjs)
- [Python](python/example.py)
- [Java](java/Example.java)
- [C#](csharp/Program.cs)
- [Go](go/main.go)

Set `CDPFLEET_API_KEY` and replace the placeholder proxy with yours. Install the client named at the top of each file.
