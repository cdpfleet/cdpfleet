# Proxy pool with per-host rules

Spread traffic over two residential exits and send CDN assets through a datacenter proxy. See [Proxies](https://cdpfleet.com/docs/proxies).

- [Node.js](node/example.mjs)
- [Python](python/example.py)
- [Java](java/Example.java)
- [C#](csharp/Program.cs)
- [Go](go/main.go)

Set `CDPFLEET_API_KEY` and replace the placeholder proxy with yours. Install the client named at the top of each file.
