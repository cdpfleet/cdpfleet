# Chrome with a pinned older major version

Lock to a specific Chrome major for reproducibility or to match a target site's expected browser. The `version` option accepts a major number; cdpfleet keeps the two most recent previous majors available.

- [Node.js](node/example.mjs)
- [Python](python/example.py)
- [Java](java/Example.java)
- [C#](csharp/Program.cs)
- [Go](go/main.go)

Set `CDPFLEET_API_KEY` and replace the placeholder proxy with yours. Install the client named at the top of each file.
