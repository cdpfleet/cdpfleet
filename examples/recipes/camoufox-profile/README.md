# Camoufox that keeps the same device and login

A Camoufox profile keeps its device: the fingerprint generated on the first launch (here a Windows one) is saved with the logins and reused, so the site sees the same computer every time. Later launches ignore fingerprint options; keep the profile on one country's exit. See [Persistent profiles](https://cdpfleet.com/docs/profiles).

- [Node.js](node/example.mjs)
- [Python](python/example.py)
- [Java](java/Example.java)
- [C#](csharp/Program.cs)
- [Go](go/main.go)

Set `CDPFLEET_API_KEY` and replace the placeholder proxy with yours. Install the client named at the top of each file.
