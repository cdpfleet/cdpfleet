# Camoufox with a fixed screen and window

Pin the persona's screen to common laptop sizes and the window to 1366×768 so screenshots and layouts are the same on every run, while the rest of the identity is still generated.

- [Node.js](node/example.mjs)
- [Python](python/example.py)
- [Java](java/Example.java)
- [C#](csharp/Program.cs)
- [Go](go/main.go)

Set `CDPFLEET_API_KEY` and replace the placeholder proxy with yours. Install the client named at the top of each file.
