# Camoufox: pinned version, macOS persona, no images

A reproducible Firefox 150 identity that reports macOS, matches its timezone and locale to the proxy, and skips images to save proxy bandwidth. `main_world_eval` lets your checks read the page's own world (`mw:` prefix).

- [Node.js](node/example.mjs)
- [Python](python/example.py)
- [Java](java/Example.java)
- [C#](csharp/Program.cs)
- [Go](go/main.go)

Set `CDPFLEET_API_KEY` and replace the placeholder proxy with yours. Install the client named at the top of each file.
