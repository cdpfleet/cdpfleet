# Camoufox with exact fingerprint values

Override single properties of the generated identity with `config` — here 8 CPU cores, no touch screen and a 1920×1080 screen — while Camoufox keeps everything else consistent.

- [Node.js](node/example.mjs)
- [Python](python/example.py)
- [Java](java/Example.java)
- [C#](csharp/Program.cs)
- [Go](go/main.go)

Set `CDPFLEET_API_KEY` and replace the placeholder proxy with yours. Install the client named at the top of each file.
